# Instapro — Курсовая работа

## Реализованный функционал
- Интеграция ленты постов с API (динамический рендер).
- Добавление поста: валидация полей, загрузка фото в облако.
- Страница постов конкретного пользователя.
- Лайки: постановка/снятие, счетчик, обновление без перезагрузки. Для неавторизованных — блокировка.
- Пустое состояние: если постов нет, выводится заглушка «Пока нет постов».

## Затраченное время
Оценка: 15 ч. Факт: ~20 ч.

## Дополнительные фичи
- **Русские даты:** подключил `date-fns` (формат «19 минут назад»).
- **XSS-защита:** HTML-теги в описаниях экранируются и выводятся как текст.
- **Битые картинки:** если ссылка на фото не работает, картинка скрывается, чтобы не ломать верстку.
- **UI-плюшки:** легкая анимация сердечка при лайке и тень при наведении на карточку поста.
